Conga Support Toolkit privacy policy

Effective October 27, 2026

Conga Support Toolkit is a Chrome extension for Conga's support team. It takes a support engineer from a Salesforce Org ID to that org's Subscriber Support login page in Conga's License Management Org (LMO). In Conga's Jira and on other websites the engineer chooses, it also shows next to each Org ID on the page whether the org is valid. This policy explains what the extension reads, where that data goes and what it keeps.

In short

  • The extension sends data only to the Salesforce org set as the LMO in its options (by default https://apttus2.my.salesforce.com), using the session you already have there.
  • It reads web pages only where Org ID links are on: in Conga's Jira (conga.atlassian.net), where they're on unless you switch them off, and on sites where you switch them on. It reads them only to find Org IDs. The page text stays in your browser; only the Org IDs go to the LMO.
  • It has no analytics, tracking, advertising or remote code.
  • It doesn't sell or share data with anyone.

What the extension keeps

  • Settings (LMO URL, single sign-on launcher URL, auto-paste on or off), in Chrome's sync storage. They follow your Chrome profile if Chrome Sync is on.
  • Short-lived working state in Chrome's session storage: the background sign-in tab, the Org ID being checked while sign-in runs, the last Org ID seen on the clipboard, the tabs being taken to the login page, and the last error. Session storage lives in memory and is cleared when Chrome closes; work in progress expires after 15 minutes.
  • The API name of the LMO's login-permission field, in Chrome's local storage, refreshed weekly. It contains no personal data.
  • The sites where Org ID links are on (host names, such as conga.atlassian.net), in Chrome's local storage, until you switch them off. It also notes there that Conga's Jira was switched on by default, so it stays off once you switch it off.
  • Recent check results (session, license and permission checks) for Org IDs on those sites, in the extension's memory only, for up to 5 minutes, so that reloading a page doesn't look the same orgs up again.

The extension never saves your session cookie, license details, page text or clipboard text other than an Org ID.

Signing in

If you aren't signed in to the LMO, the extension opens the single sign-on link set in its options (by default, Conga's Microsoft My Apps link for the LMO) in a background tab. That is the normal Microsoft and Salesforce sign-in. The extension never sees your password. A web page never starts a sign-in by itself: on pages with Org ID links, signing in starts only when you click Sign in to the LMO or open a login page, and it happens in a tab you can see.

Sharing

Data from the extension is not sold, not transferred to third parties, not used for advertising or anything unrelated to the extension's purpose, and not used to determine creditworthiness or for lending.

Your choices

  • Turn off auto-paste in the options to stop the popup reading the clipboard when it opens.
  • Switch Org ID links off for a site in the popup, or remove the site under Org ID links in the options. The extension then stops reading that site and gives back its access to it, apart from Conga's Jira and Salesforce sites, which it keeps access to but no longer reads. Taking the access away in Chrome's own settings for the extension does the same.
  • Restore defaults in the options resets the settings.
  • Removing the extension deletes everything it stored.

Changes

If the extension's data handling changes, this policy and its effective date will be updated.
