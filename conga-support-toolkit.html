Conga Support Toolkit privacy policy

Effective October 16, 2026

Conga Support Toolkit is a Chrome extension for Conga's support team. It takes a support engineer from a Salesforce Org ID to that org's Subscriber Support login page in Conga's License Management Org (LMO). This policy explains what the extension reads, where that data goes and what it keeps.

In short

  • The extension sends data only to the Salesforce org set as the LMO in its options (by default https://apttus2.my.salesforce.com), using the session you already have there.
  • It has no analytics, tracking, advertising or remote code.
  • It doesn't sell or share data with anyone.

What the extension keeps

  • Settings (LMO URL, single sign-on launcher URL, auto-paste on or off), in Chrome's sync storage. They follow your Chrome profile if Chrome Sync is on.
  • Short-lived working state in Chrome's session storage: the background sign-in tab, the Org ID being checked while sign-in runs, the last Org ID seen on the clipboard, the tabs being taken to the login page, and the last error. Session storage lives in memory and is cleared when Chrome closes; work in progress expires after 15 minutes.
  • The API name of the LMO's login-permission field, in Chrome's local storage, refreshed weekly. It contains no personal data.

The extension never stores your session cookie, license details or clipboard text other than an Org ID.

Signing in

If you aren't signed in to the LMO, the extension opens the single sign-on link set in its options (by default, Conga's Microsoft My Apps link for the LMO) in a background tab. That is the normal Microsoft and Salesforce sign-in. The extension never sees your password.

Sharing

Data from the extension is not sold, not transferred to third parties, not used for advertising or anything unrelated to the extension's purpose, and not used to determine creditworthiness or for lending.

Your choices

  • Turn off auto-paste in the options to stop the popup reading the clipboard when it opens.
  • Restore defaults in the options resets the settings.
  • Removing the extension deletes everything it stored.

Changes

If the extension's data handling changes, this policy and its effective date will be updated.
